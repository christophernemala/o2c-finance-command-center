# O2C Design Engineering — quick entry

Use the installable skill entry point in [`SKILL.md`](SKILL.md). This file is a quick navigation alias for environments that request lowercase `skill.md`.

Start with [the source ledger](reference.md), then open only the topic files needed for the current design or engineering task. All claims must remain attributed to the source that supports them; Prompt Master is prompt-writing guidance, not a UI system.

Workflow: inspect the existing product contract → select only verified patterns → implement within finance/security boundaries → test and report evidence. See [best-practices.md](best-practices.md) for reusable task prompts and [review.md](review.md) for acceptance checks.
